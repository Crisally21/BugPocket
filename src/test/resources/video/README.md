# Тестовые видеоролики

`sample.mov`, `sample.mkv`, `sample.avi`, `sample.webm` — синтетические ролики:
синий кадр 64 × 48 пикселей, 5 кадров при 5 кадрах/с, без аудио.
Созданы локально через FFmpegFrameRecorder из JavaCV 1.5.13 (FFmpeg 8.0.1).
Контейнер задавался явно: mov, matroska, avi, webm соответственно.
MOV/MKV/AVI используют MPEG-4 Part 2, WEBM — VP8; формат пикселей YUV420P.
Это отдельные закодированные файлы, а не переименованные копии MP4.

Тест проверяет декодирование каждого контейнера, PNG-сигнатуру превью и его
размеры. Он не гарантирует поддержку всех возможных кодеков внутри контейнера.
Существующий MP4 используется отдельным тестом.

`audio-only.m4a` — одна секунда синтетической тишины AAC, 44 100 Гц,
моно, контейнер M4A, без видеодорожки. Создан через FFmpegFrameRecorder
из той же версии JavaCV. Проверяет отказ при отсутствии кадра и очистку файла.

Для границ 24 999 999 / 25 000 000 / 25 000 001 байт тест дополняет
`sample.mov` корректным атомом `free` в памяти. Видеоданные и их смещения
сохраняются, большие файлы в репозитории не хранятся.

`frame-5000x4000.mkv` и `frame-5000x4002.mkv` — по одному чёрному кадру,
1 кадр/с, без аудио, Matroska/FFV1, YUV420P. Созданы через JavaCV 1.5.13.
Размеры и возможность декодирования проверены через FFmpegFrameGrabber.
Первый образец содержит ровно 20 000 000 пикселей, второй — 20 010 000.
Они предназначены для проверки границы размера исходного кадра.

`frame-1920x1080.mkv` и `frame-1080x1920.mkv` — по одному красному кадру,
1 кадр/с, без аудио, Matroska/FFV1, YUV420P, созданы через JavaCV 1.5.13.
Проверяют уменьшение до 1280 × 720 и 405 × 720, сохранение цвета и очистку.
