# Тестовые видеоролики

`sample.mov`, `sample.mkv`, `sample.avi`, `sample.webm` — синтетические ролики:
синий кадр 64 × 48 пикселей, 5 кадров при 5 кадрах/с, без аудио.
Созданы локально через FFmpegFrameRecorder из JavaCV 1.5.13 (FFmpeg 8.0.1).
Контейнер задавался явно: mov, matroska, avi, webm соответственно.
MOV/MKV/AVI используют MPEG-4 Part 2, WEBM — VP8; формат пикселей YUV420P.
Это отдельные закодированные файлы, а не переименованные копии MP4.

Тест проверяет декодирование каждого контейнера, PNG-сигнатуру превью и его
размеры. Он не гарантирует поддержку всех возможных кодеков внутри контейнера.
Существующий MP4 используется отдельным тестом.
